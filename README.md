# Instructions:

Click the "Add new project" card to add a new project.
Click the delete button to delete the card.
Click the delete all button to delete all the cards.
Statistics updates automatically.

## How it works:

1. The "Add new project" card takes your input and stores it in localStorage as an object.
2. RenderProjectCards() then uses the objects stored in localStorage to generate the Project cards and update the statistics.
3. The delete buttons remove the objects from localStorage.
